# Savvy Mother International School Website

Official website project for **Savvy Mother International School**, Rewa, Madhya Pradesh.

## 🌟 Overview
Savvy Mother International School is dedicated to holistic learning, combining academic excellence with co-curricular opportunities (Robotics, AI, Abacus, Sports, and Cultural Celebrations).

## 📁 Project Structure
- `index.html` - Homepage
- `about/` - School profile, Campus, Faculty, and Leadership messages
- `academics/` - Pre-Primary, Middle, Secondary, and Senior Secondary
- `admissions/` - Inquiry, Process, and Eligibility
- `css/` - Master stylesheets
- `js/` - Vanilla JavaScript functionality
- `images/` - Media and assets

## 🚀 Getting Started
Open `index.html` in any modern web browser or serve via a local HTTP server.
